# Лифт в ад — сборка для проверки

Готовую сборку Windows 64-bit скачайте на странице [Releases](https://github.com/komota33-ship-it/e/releases). Распакуйте ZIP и запустите `Lift-v-ad.exe`, оставив `Lift-v-ad.pck` рядом.

Файлы в `parts/` нужны только для сборки релиза GitHub Actions; каждый из них меньше 25 МиБ. Исходный проект находится в рабочей среде Codex, а этот репозиторий сейчас служит точкой выдачи тестовой сборки.
