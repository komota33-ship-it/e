# Лифт в ад · прототип 0.11

**Нативный проект Godot 4.6 доступен в этом репозитории.** Откройте [project.godot](project.godot); управление, реализованные системы и проверки перечислены в [описании версии Godot](godot/README.md). Браузерная версия ниже сохранена отдельно.

Готовая сборка для Windows доступна в [Releases](https://github.com/komota33-ship-it/e/releases). Распакуйте архив и запустите `Lift-v-ad.exe`, оставив `Lift-v-ad.pck` рядом. Все 50 этажей используют отдельные цельные панорамы без вставок чужих секций; интерфейс убежища показывает найденных обитателей после их спасения.

Игра с видом сбоку по концепту «Башня Атлас». Новое прохождение начинается на игровой крыше, затем ведёт через этажи 50–2 в бункер B1. Управление прежде всего рассчитано на компьютер. Все изображения встроены в автономную HTML-сборку; интернет во время игры не нужен.

## Запуск и сборка

Откройте `dist/lift-v-ad.html` в современном браузере после сборки. Для разработки нужен Node.js 18+, устанавливать npm-зависимости не требуется:

```sh
npm start
npm run check
npm test
npm run build
```

Сервер слушает порт 3000. Другой порт задаётся через `PORT=8080 npm start`.

## Управление

| Действие                         | Кнопки                       |
| -------------------------------- | ---------------------------- |
| Движение                         | A / D или стрелки            |
| Бег / уклонение                  | Shift + движение / Q         |
| Прицеливание / стрельба          | Мышь / ЛКМ, также F          |
| Быстрое оружие                   | 1–3, по числу слотов рюкзака |
| Перезарядка                      | R                            |
| Дверь, обыск, лестница, лифт     | E                            |
| Рюкзак                           | I или Tab; I / Esc закрывает |
| Архив найденных записей          | J или кнопка «Архив»         |
| Граната / лечение / нож / фонарь | G / H / V / L                |
| Пауза                            | Esc                          |

В рюкзаке: перетащите предмет мышью или выберите его и щёлкните свободную ячейку. R поворачивает выбранный предмет. Кнопки справа позволяют использовать, экипировать, объединить или оставить предмет на полу. Брошенные предметы доступны в сумке рядом с героем. Во время открытого рюкзака бой приостанавливается.

## Исправления в рабочей сборке

**Три концовки.** После победы над Объектом 0 у шлюза B1 открывается выбор: «Эвакуация», «Спасение» или «Истина». Для каждой концовки сгенерирована отдельная иллюстрация: она показана над сюжетом из 200–300 слов. Выбор останавливает бой, его можно закрыть Esc и вернуться к шлюзу; выполненные концовки помечаются при следующем прохождении и сохраняются отдельно от чекпоинта. Проверка `GAME_URL=http://127.0.0.1:3000 python3 tests/endings_smoke.py` проходит все три ветви, загрузку изображений и историю.

**Радиосообщения.** На ключевых этажах во время игры появляются короткие реплики Елены, Маркуса и Мамы: по 5–10 авторских строк для каждого персонажа, включая реакции на двойников Елены и решение пощадить или убить Маму. Реплики не останавливают бой, сменяются по времени, при паузе замирают и при переходе на другой этаж не наслаиваются друг на друга. Проверка `GAME_URL=http://127.0.0.1:3000 python3 tests/story_smoke.py` проходит сюжетные события в браузере.

**Записи и архив.** На 30 выбранных этажах в существующих столах и шкафах лежат сюжетные записи по 50–100 слов: от первых приказов «Атласа» до B1. Помеченную мебель нужно обыскать обычной клавишей E. Находка открывает архив и останавливает бой; после закрытия можно повторно открыть контейнер и взять его обычный лут. Прочитанное сохраняется отдельно от чекпоинта и остаётся доступным по J после смерти и нового прохождения. Проверка `GAME_URL=http://127.0.0.1:3000 python3 tests/journal_smoke.py` проходит все точки размещения и сохранение после перезагрузки.

**Меню, сохранение и звук.** Главное меню получило отдельный нарисованный фон пустого лифтового холла: игровые враги и HUD за ним скрыты. Меню паузы позволяет отдельно сохранить текущее положение и состояние комнаты, вернуться в главное меню без автоматического сохранения и открыть настройки. Звук, громкость, отдельная громкость музыки и тряска камеры сохраняются локально. Тихая музыка написана как зацикленная последовательность минорных синтезаторных аккордов и редких металлических нот; она генерируется Web Audio без внешних файлов. Выстрелы пистолета и дробовика, рычание атакующих заражённых и сигналы действий синтезируются Web Audio и работают в автономной сборке. Пули показаны короткими движущимися трассерами. Дробь пробивает первого зомби без перка; перк «Пробитие» добавляет следующие цели. Попадание в игровую логику по-прежнему считается в момент выстрела. Кнопка выхода закрывает игру переходом на пустую страницу браузера.

**HUD и горизонтальное управление.** Панели получили более компактную мягкую форму и шесть нарисованных значков полевых приборов. Табличка этажа уменьшена; номера быстрых слотов расположены внутри квадратов снизу слева. Прыжок удалён из управления и подсказок: герой перемещается только влево и вправо, а двери и лифт работают через E.

**«Елена?», этаж 30.** Сюжетный босс из концепта показан как заражённое эхо голоса из рации: 800 HP, залп из трёх бирюзовых импульсов и две фазы с короткоживущими двойниками при 50% и 20% здоровья. Двойники полупрозрачны, исчезают от урона или через семь секунд и не дают ДНК. Победа оставляет припасы и открывает лифт; это пока намёк на обман, а не окончательное раскрытие тайны Елены. Отдельные нарисованные атласы используются для ходьбы, атаки и смерти. Проверка `GAME_URL=http://127.0.0.1:3000 python3 tests/elena_smoke.py` сохраняет кадры в `dist/`.

**Мама, этаж 25.** Пятый промежуточный босс из списка концепта: 700 HP, тяжёлый удар и призыв двух заражённых с ограничением пяти живых последователей. У порога 12% здоровья она складывает оружие и прекращает бой. Рядом с ней E позволяет пощадить её: игрок получает 100 ДНК, антидот и припасы, выбор сохраняется вместе с текущим состоянием этажа. Если продолжить стрелять, победа даёт 200 ДНК и боеприпасы. В обоих случаях открывается лифт на 24-й этаж. Для боя, смерти и сдачи нарисованы отдельные атласы; проверка `GAME_URL=http://127.0.0.1:3000 python3 tests/mama_smoke.py` проходит обе развилки и сохраняет кадры в `dist/`.

**Химера, этаж 20.** Четвёртый промежуточный босс из концепта: 600 HP и две случайные мутации из четырёх — скорость ×1,5, броня (−30% входящего урона), усиленный кислотный плевок или регенерация 4 HP/с после 2,5 секунды без попаданий. Обычный плевок доступен Химере всегда; мутация усиливает его урон с 12 до 16. Мутации показаны под полоской здоровья. Для Химеры нарисованы отдельные атласы движения, ходьбы, кислотной атаки и падения. Пока она жива, лифт заблокирован; после победы рядом остаются припасы, начисляются 200 ДНК и открывается путь на 19-й этаж. Проверка `GAME_URL=http://127.0.0.1:3000 python3 tests/chimera_smoke.py` сохраняет кадры боя в `dist/`.

**Броненосец, этаж 15.** Добавлен третий промежуточный босс из концепта: 500 HP, отдельный атлас 4×3, тяжёлый удар щитом с закреплённой опорной стопой. Его щит уменьшает входящий урон спереди на 85%; открытая спина получает ×1,5 урона. Направление считается от источника удара, включая выстрел, нож и гранату. Лифт открывается после победы; награда — припасы и 200 ДНК.

**Крикун-Альфа, этаж 10.** Добавлен второй промежуточный босс из концепта: 250 HP, отдельный атлас 4×3, крик с вызовом пяти заражённых и полоска здоровья. Лифт открывается после победы; награда — сумка припасов и 200 ДНК (100 за мини-босса + 100 за победу).

**Толстяк-Матка, этаж 5.** Добавлен первый промежуточный босс из концепта: 300 HP, призыв до трёх заражённых за атаку с ограничением восьми живых призванных. Победа открывает лифт, даёт 100 ДНК за убийство, дополнительные 100 ДНК и сумку снабжения. Полоска здоровья и отдельный атлас 4×3 показывают бой; чекпоинт на 5-м этаже работает как раньше.

**Кислота на полу.** Снаряды Плевуна и Объекта 0 показывают место ожидаемого падения на полу. Опасная лужа получила читаемую кромку и мягкое свечение, которое гаснет вместе с пятисекундным действием кислоты. Проверка `tests/boss_volley_smoke.py` сохраняет кадры `dist/acid-warning-work.png` и `dist/acid-puddle-work.png`.

**Залп Объекта 0.** Для дальнего удара подключён отдельный восьмикадровый атлас: кислота накапливается в когте, затем летят три снаряда с разным разлётом. Их точка появления привязана к вытянутому когтю активного кадра, а не к центру тела. Проверка `GAME_URL=http://127.0.0.1:3000 python3 tests/boss_volley_smoke.py` проверяет восемь поз, источник и три снаряда; `tests/record_enemy_preview.py boss_volley` записывает движение и атаку.

**Объём пола и опора персонажей.** В интерьерах стык стены и пола расположен на 30 игровых единиц позади линии ног. Нарисованная поверхность пола продолжается на 46 единиц перед ней; передняя кромка и затемнённый торец показывают толщину перекрытия. Сцена собирается в одно полотно: сгенерированный атлас `floor_surfaces.png` задаёт шесть покрытий — офисную плитку, лабораторную плитку, паркет, плитку торгового центра, бетон паркинга и металл бункера. Верхняя поверхность и торец перекрытия рисуются отдельно с общей кромкой; верхняя архитектура сохраняет масштаб. Пока атлас загружается, используется пол исходной сцены. Двери, лифты, мебель и их точки взаимодействия используют ту же проекцию, включая зеркальные комнаты. Проекция крыши сохранена. Добавлена мягкая контактная тень вокруг прежнего тёмного пятна под ногами. Физическая линия земли и прицеливание не менялись. Управление героем ограничено горизонтальным движением; этажи сменяются через двери и лифт.

Проверки пола: `node tests/depth.test.mjs` охватывает 51 этаж и 173 комнаты; `GAME_URL=http://127.0.0.1:3000 python3 tests/floor_depth_smoke.py` сохраняет примеры семи зон и четырёх комнат в `dist/floor-depth-*.png` и проверяет совпадение точек взаимодействия с изображением.

**Падение Курьера.** Добавлен отдельный восьмикадровый атлас: потеря равновесия, опора на колено и руки, затем положение лёжа. Поза не меняет масштаб и не сдвигает место смерти; обе стороны и все кадры проверяются в браузере. Перезапуск возвращает обычную стойку.

**Походка и удар Объекта 0.** Добавлены отдельные восьмикадровые атласы ходьбы и удара когтем. Цикл ходьбы связан с расстоянием (62 единицы), в том числе при прежнем ускорении ×2,2 ниже половины здоровья. Удар использует прежние фазы 0,5 / 0,18 / 0,65 секунды и урон 28; передняя стопа закреплена, масштаб постоянен и не зависит от поднятой руки. Базовые 1500 HP сохранены. Кислотный залп пока использует прежние рисунки. Падение использует отдельные восемь кадров за прежние 1,2 секунды, с общим масштабом и постоянной горизонтальной привязкой. Тело сохраняет мировые координаты места гибели и сдвигается на экране только вместе с камерой. Проверяются приоритеты ходьбы, ближнего удара, залпа и смерти; залп по-прежнему выпускает три снаряда один раз. Адаптация босса к оружию игрока и дополнительные сюжетные фазы пока не реализованы.

**Походка и удар Броневика.** Подключены отдельные восьмикадровые атласы. Цикл ходьбы связан с расстоянием (48 единиц), щит остаётся перед телом. Удар использует три позы подготовки, две толчка и три восстановления; передняя стопа закреплена, масштаб общий. Сохранены прежние фазы ближней атаки 0,3 / 0,13 / 0,43 секунды, урон 15 и защита 70% спереди. Проверяются оба направления, единственное попадание при разной частоте кадров, отход из зоны удара, прерывание замаха и приоритет смерти. Падение Броневика использует восемь отдельных кадров за прежние 0,9 секунды: колени подгибаются, щит касается пола, тело заваливается на бок. Масштаб и горизонтальная привязка постоянны; щит остаётся с телом. Гибель прерывает ходьбу и любую фазу удара. Награда 25 ДНК и пятно крови появляются один раз, стадия падения сохраняется при возвращении в комнату.

**Походка и крик Крикуна.** Добавлены два отдельных восьмикадровых атласа. Ходьба связана с расстоянием (64 единицы на цикл); крик проходит вдох, активную фазу и восстановление за прежние 0,65 / 0,35 / 0,65 секунды. Передняя стопа остаётся на месте, масштаб постоянен. Волна возникает у рта первого активного кадра; призыв пяти зомби срабатывает один раз, с учётом общего лимита 40 врагов. Попадание во время вдоха прерывает призыв; смерть не создаёт повторную волну или награду. Сам крик не наносит урона. Падение Крикуна использует отдельные восемь кадров: потеря опоры, колени, опора на руки и оседание на бок. Длительность — прежние 0,9 секунды, масштаб единый. Финальная поза остаётся неподвижной; возвращение в комнату сохраняет стадию падения и единственное пятно крови. Проверена гибель при ходьбе и во всех фазах крика в обоих направлениях.

**Движение и атака Толстяка.** Подключены два отдельных атласа по восемь кадров: тяжёлая походка и удар обеими руками. Походка связана с расстоянием — прежние 44 игровые единицы на цикл. Удар использует три кадра замаха, два активной фазы и три восстановления; прежние времена 0,5 / 0,18 / 0,65 секунды и урон 20 сохранены. Масштаб каждого цикла постоянен; поднятые руки не уменьшают тело, передняя стопа закреплена во время удара.

Падение Толстяка использует восемь отдельных кадров за 0,65 с. Взрыв начинается у живота лежащего тела; кровь, слизь и фрагменты выходят из той же точки. Эффект отражает положение тела при развороте и не рисуется под полом.

Проверена смерть в замахе, ударе и восстановлении: атака прекращается, взрыв срабатывает через прежние 0,65 секунды, повреждает героя один раз и заменяет тело эффектом.

**Падение Плевуна.** Добавлен отдельный атлас из восьми кадров: потеря опоры, падение на колени и ладони, оседание на бок. Длительность остаётся 0,9 секунды; масштаб общий, последняя поза неподвижна. Слизь создаётся существующими частицами и пятном на полу, без нарисованной на теле второй лужи. Проверена гибель в подготовке, активной фазе и восстановлении плевка: новых снарядов после смерти нет, уже выпущенный продолжает лететь. Тело, награда 12 ДНК и пятно появляются однократно; возвращение в комнату не перезапускает падение. Пятно от тела остаётся декоративным, как прежде.

**Походка Плевуна.** Подключён отдельный восьмикадровый атлас вместо четырёх кадров основного изображения. Цикл зависит от пройденного расстояния: 58 игровых единиц на полный шаговый цикл, как прежде. Размер рисунка постоянен, разворот использует отражение, нижняя опорная точка остаётся на полу. Проверены все восемь кадров, переход в стойку при остановке, приоритет плевка над ходьбой и возврат к движению после атаки. Скорость и поведение врага не изменены.

**Атака Плевуна.** Добавлен отдельный атлас из восьми кадров: вдох, подготовка, выброс кислоты и восстановление. Фазы сохраняют прежние длительности 0,5 / 0,14 / 0,55 секунды. Передняя стопа закреплена, масштаб постоянен. Снаряд появляется у губ активного кадра с учётом направления и размера врага; кислотная струя не нарисована на самом теле, поэтому неподвижного дублирующего снаряда нет. Цель фиксируется при начале подготовки. Урон 12, скорость и правила попаданий прежние. При отсутствии нового изображения используется прежняя точка выброса; залп босса не изменён. Смерть Плевуна использует отдельный восьмикадровый атлас.

**Границы кадров ходьбы.** При поиске промежутков между рисунками теперь сохраняется прозрачный отступ, как у атак и падений. Это устраняет касание края ботинка границей кадра в атласе Объекта 0; проверка охватывает все атласы ходьбы.

**Загрузка анимаций.** Исправлен кэш кадров: если меню успело нарисовать персонажа до загрузки дополнительных атласов, они теперь подключаются при следующей отрисовке. Раньше могли сохраняться старые движения и атаки до перезапуска страницы. Проверена поочерёдная загрузка ходьбы, падения, рывка и ближнего удара; при неизменных изображениях повторного разбора нет.

**Ближняя атака Ходока.** Добавлен собственный атлас из восьми кадров: подъём рук, замах, захват и возвращение в стойку. Сохранены медленные фазы 0,3 / 0,13 / 0,43 секунды и прежний урон. Общий масштаб и закреплённая передняя стопа предотвращают растягивание тела и сдвиг при вытягивании рук. Проверены оба направления, единственное попадание, промах при отходе, прерывание замаха и переход к смерти.

**Ближняя атака Бегуна.** Добавлен отдельный атлас из восьми кадров: три позы замаха, две удара и три восстановления. Кадры связаны с прежними фазами атаки: 0,17 / 0,12 / 0,28 секунды. Передняя стопа закреплена на полу, масштаб один для всех кадров; вытягивание руки не сдвигает тело из-за изменения силуэта. Урон, заражение и дальность удара прежние. Проверены единственное попадание, уход за пределы досягаемости, прерывание замаха попаданием и приоритет смерти над атакой.

**Рывок Бегуна.** Новый атлас из восьми кадров: три позы подготовки, две выпада и три восстановления. Рисунок выбирается по фазе реальной атаки: 0,26 с подготовки, 0,27 с движения и 0,4 с восстановления; повторный рывок — не раньше трёх секунд. Все кадры используют единый масштаб, стопы стоят на полу. Обычный ближний удар использует отдельный восьмикадровый атлас.

Исправлена зависимость дальности рывка от частоты кадров: теперь учитывается только часть обновления внутри активной фазы, включая её начало и конец. Базовая дальность составляет ровно 83,7 единицы (310 × 0,27), до границ локации и модификаторов скорости. Контакт проверяется вдоль пройденного за кадр отрезка, урон наносится один раз. Смерть прерывает рывок и включает атлас падения.

**Падение Бегуна.** Сгенерированы восемь последовательных кадров: потеря опоры, падение на колено и ладонь, приземление на бок и неподвижное тело. Единый масштаб и точка привязки сохраняются во всём цикле; последнее положение фиксируется. Падение длится 0,9 секунды, как прежде. Проверены смертельные попадания во время бега, замаха, активной фазы и восстановления рывка/удара: погибший враг больше не движется и не наносит урон, ДНК выдаётся один раз.

**Падение Ходока.** Новый прозрачный атлас содержит восемь последовательных поз вместо четырёх: подгибание коленей, опора на руку, падение грудью и неподвижное тело. Цикл длится прежние 0,9 секунды и останавливается на последнем кадре. Масштаб один для всех фаз, начало согласовано с ростом живого врага; общая горизонтальная точка привязки сохраняет движение тела в рисунке и исключает смещение из-за разных полей ячеек. Падение отражается вместе с направлением врага. Награда и тело создаются один раз; повторного урона после смерти нет.

**Бегун.** Сгенерирован отдельный цикл бега из восьми цельных кадров с прежним обликом. Один цикл соответствует 100 игровым единицам перемещения; остановка не прокручивает ноги, разворот отражает тот же рисунок. В фазе полёта всё тело плавно приподнимается до четырёх единиц, в фазе опоры стопы возвращаются на пол. Подъём только визуальный: столкновения, скорость, рывок и урон прежние. В стойке используется основной атлас; обычный удар, рывок и смерть используют отдельные восьмикадровые атласы.

**Анимация Ходока и восстановление атак.** Для Ходока сгенерирован отдельный атлас ходьбы 4×2: восемь кадров вместо прежних четырёх. Кадр зависит от пройденного расстояния, цикл — 60 игровых единиц; разворот использует тот же рисунок с отражением. Весь цикл имеет единый равномерный масштаб по обеим осям, стопы привязаны к линии пола. Отдельные восьмикадровые атласы движения подключены всем шести обычным типам зомби. В автономную сборку встроены 69 используемых изображений.

Ходок, Бегун, Толстяк и Броневик теперь возвращают руки через промежуточную позу к стойке в течение существующего восстановления атаки. Плевун и Крикун завершают собственную позу восстановления и переходят к стойке, не проигрывая плевок/крик задом наперёд. Скорость движения, замахи, момент урона, задержки между атаками, выброс кислоты и призыв орды не изменены. Кадры смерти остальных заражённых и задержка взрыва Толстяка остаются прежними. Это частичная визуальная доработка: остальные циклы ходьбы и новые более подробные падения ещё предстоит нарисовать.

**Полноценная дробь.** Помповый дробовик теперь выпускает 6 дробин по 10 базового урона с темпом 1,2 выстрела/с — параметры Remington из концепта. Магазин остаётся на 6 патронов (9 с расширением). Один залп расходует один патрон и создаёт один шум выстрела; у дробин шесть отдельных трасс. Фиксированный симметричный веер шириной 12° — начальная настройка разброса, отсутствующая в документе. Он поворачивается вместе с прицелом и позволяет задевать несколько целей по краям.

Для каждой дробины отдельно учитываются первые две цели (и дополнительные с перком «Пробитие»), голова/тело/ноги, передняя броня и дистанция. Сохранено ослабление по дистанции до 30% базового урона; дополнительно на дальности часть дробин проходит мимо цели. До перков и зон максимальный урон шести дробин — 60, но фактический зависит от расстояния и попаданий. Все траектории считаются до нанесения урона: гибель переднего зомби от одной дробины не позволяет остальным обойти его без пробития. Критический бросок общий для всего залпа, как прежде для выстрела; лазер прибавляет шанс один раз. Урон суммируется по каждой цели и применяется один раз, сохраняя одну смерть, награду ДНК и подпись попадания. Попадание любой дробины в ноги замедляет цель. Пистолет сохраняет одиночную пулю. Сохранённые экземпляры дробовика, боезапас и обвесы совместимы без миграции.

**Удача и Коллекционер.** «Удача» в ветке «Психо» повышает шанс дополнительного снаряжения на 10/20/30%; цены рангов — 200/400/800 ДНК. «Коллекционер» открывается при Удаче 3 и Мародёре 2 и добавляет ещё 30%, до суммарных +60%. Покупки действуют со следующего старта или загрузки чекпоинта; старые профили получают нулевую Удачу. Всего доступны 23 перка и 10 синергий.

Бонус относительный: шанс оружия/брони 24% становится 31,2% с Удачей 3 и 38,4% с Коллекционером; рюкзака — с 12% до 15,6% и 19,2%. В мастерских шанс именно обвеса составляет 27% (из общего 45%-го броска на пружины/обвесы); он растёт до 35,1% и 43,2%. В прочих немедицинских контейнерах ниже офисов обвесы растут с 12% до 15,6% и 19,2%. Сами пружины и обычные припасы не получают бонуса Удачи. В этой реализации «редкий лут» означает оружие, броню, рюкзаки и обвесы из существующих таблиц сектора, без отдельной системы цветовых редкостей. Цены и трактовка относительных процентов — начальная настройка; документ задаёт величины бонусов, но не таблицы редкости.

Бонус добавляет предмет только при неудаче исходного броска соответствующей категории. Исходные вещи, их количество, прочность и патроны сохраняются. Повышение Удачи не заменяет находки прежних рангов. Добыча рассчитывается один раз при создании помещения; отмена обыска, повторное открытие и возвращение в комнату не дают новых попыток. «Мародёр» продолжает отдельно добавлять обычные припасы. Фиксированные припасы крыши, медшкафы, оставленные игроком сумки и сюжетный ящик B1 не меняются. Ловушки и засады рассчитываются независимо. Ранг Удачи сохраняется в профиле, а собранные вещи — в обычном чекпоинте; сам этаж после загрузки создаётся заново, как прежде.

**Зомби в контейнере.** Добавлен риск обыска из концепта: 5% стационарных контейнеров ниже учебного 50-го этажа скрывают Ходока. Крыша, первый учебный этаж и сумки с выброшенными вещами безопасны. Засада рассчитывается отдельным постоянным seed при создании помещения: лут и ловушки от неё не меняются, осмотр «Внимательным» её не раскрывает. Отмена обыска не активирует засаду и не меняет результат.

После завершения обыска заражённый появляется у мебели; окно добычи автоматически не открывается, чтобы игрок увидел угрозу. Припасы остаются в контейнере и доступны следующим нажатием E. Появление занимает 0,35 секунды с пылью и переходом прозрачности без изменения пропорций тела; затем перед атакой проходит ещё 0,9 секунды и обычный замах Ходока. Это начальные настройки реакции, не заданные концептом. Здоровье соответствует сектору. Зомби можно атаковать сразу; его смерть даёт обычную награду один раз.

Засада и ловушка могут встретиться вместе: предупреждение об обезвреживании имеет приоритет, «Сапёр» влияет только на устройство. Если в помещении уже 40 живых врагов, появление ждёт свободного места. Открытый контейнер не создаёт новых зомби при повторном нажатии E или возвращении в комнату. Пауза и инвентарь останавливают таймеры; уход из комнаты сохраняет её врагов и состояние засады. Загрузка чекпоинта, как и раньше, создаёт этаж заново.

**Электрик и Респиратор.** В ветке «Техник» добавлены два перка: защита от электрошоковых и газовых ловушек соответственно. Каждый имеет три ранга с уменьшением соответствующего урона на 50/75/100% и ценами 100/200/400 ДНК. Концепт задаёт иммунитет и общую трёхуровневую систему, но не промежуточные значения этих перков: выбранная трактовка даёт полный иммунитет на третьем ранге. Покупки применяются со следующего старта или загрузки чекпоинта; старые профили получают нулевые ранги.

Личная защита не обезвреживает устройство и не уменьшает его шум. Газ сохраняет облако и все пять секунд действия. Защита учитывает первый выброс и каждый последующий импульс; на третьем ранге попадание не изнашивает броню и не даёт краткой неуязвимости от других атак. Обезвредить ловушку вручную по E всё ещё можно. Подсказки предупреждения и активного газа показывают полный иммунитет; при частичной защите остаётся совет отойти. «Сапёр» отдельно снижает шум и оставшийся урон: например, первый ранг «Электрика» и первый ранг «Сапёра» оставляют 25% урона шока. Его третий ранг по-прежнему автоматически обезвреживает ловушки.

«Электрик» не защищает от газа, «Респиратор» — от электричества. Оба не защищают от мин, кислоты Плевуна, укусов и заражения; сирена продолжает привлекать орду. В текущей игре эти иммунитеты применяются к контейнерным ловушкам — иных источников электрического или газового урона пока нет.

**Мораль.** Новый перк ветки «Психо» даёт +10/20/30% ДНК за убийства всех заражённых, включая Объект 0. Стоимость — 150/300/600 ДНК, начальная настройка баланса: концепт задаёт бонус, но не цену этого перка. Покупка действует со следующего старта или загрузки чекпоинта. Сотые доли ДНК накапливаются в постоянном профиле: два Ходока по 5 ДНК с первым рангом дают суммарно 11, а не 10. Остаток переживает смерть, новый спуск и перезагрузку; в баланс и покупки попадают только целые единицы. Старые профили получают нулевой ранг и остаток.

Бонус за окончательную смерть от заражения по-прежнему составляет 50% уже начисленной за попытку ДНК с округлением вниз. «Мораль» второй раз к нему не применяется. Возрождение не начисляет этот бонус. На экране итогов указано, что бонус «Морали» уже включён в награду. Это перк ДНК; отдельная система морали 0–100, NPC и моральные выборы пока не реализованы.

**Внимательный.** Перк ветки Мародёр позволяет увидеть содержимое ближайшего контейнера до обыска. Цена рангов — 100/200/400 ДНК. Ранг I показывает первый предмет и число оставшихся позиций; II — названия всех предметов; III — ещё количество, прочность брони, патроны и обвесы оружия. Это начальная трактовка трёх рангов: концепт задаёт просмотр содержимого, но не различия уровней и цены. Осмотр доступен в обычной зоне взаимодействия, не открывает контейнер, не выдаёт предметы и не генерирует их заново. Скрытые ловушки не раскрываются; при предупреждении о ловушке или активном газе подсказка содержимого уступает место предупреждению. Во время обыска, крафта, паузы и инвентаря осмотр скрыт. Покупки действуют со следующего старта и сохраняются в старом формате профиля.

**Обвесы оружия.** Добавлены глушитель (−80% шума выстрела), лазер (+15 процентных пунктов к шансу крита выстрела) и расширенный магазин (+50% вместимости). Они подходят для текущих пистолета и дробовика, устанавливаются отдельно на каждый экземпляр. Выберите обвес в рюкзаке, затем оружие в блоке «Установить на оружие». Для снятия выберите оружие и нажмите нужный обвес в блоке «Обвесы».

Расширенный магазин вмещает 18 патронов у пистолета и 9 у дробовика. Установка не добавляет патроны; снятие возвращает излишек в запас. Если обвес и патроны не помещаются, операция отменяется без изменения оружия или рюкзака. Установка и снятие отменяют незавершённую перезарядку без списания патронов и сохраняют задержку между выстрелами. Масса обвесов учитывается и до, и после установки: 0,2/0,15/0,25 кг соответственно — начальные настройки баланса.

Глушитель сочетается с шумовыми бонусами рюкзака и «Призрака»; сирены, гранаты и другие источники шума не приглушает. Лазер увеличивает шанс крита только огнестрельного оружия, суммируется с перком до предела 100%, показывает линию прицела и точку на ближайшем противнике. Магазин, обвесы и боезапас сохраняются при выбрасывании, подборе, сортировке, смене рюкзака и загрузке чекпоинта. Старое оружие без обвесов загружается с базовыми характеристиками.

На верстаке доступны три рецепта из концепта: глушитель — 2 металла + 1 ткань; лазер — 1 металл + 1 электроника; расширенный магазин — 2 металла + 1 пружина. Базовое время каждого — 5 секунд, начальная настройка баланса. Обвесы и пружины встречаются в технических контейнерах; ниже офисов обвесы бывают и в обычных немедицинских контейнерах. Для четырёх предметов сгенерированы отдельные иконки. Их модели на оружии в руках героя пока не отображаются; в бою виден лазерный луч. Прицел и тактический приклад пока не реализованы.

**Ловушки при обыске.** Крыша и этаж 50 безопасны. Для стационарных контейнеров шанс ловушки составляет 10% на 49–41, 20% на 40–31, 25% на 30–21, 30% на 20–11 и 40% на 10–2/B1. Это распределение внутри заданного концептом диапазона 10–40%. Тип и наличие ловушки определяются при создании комнаты независимо от добычи. Оставленные игроком сумки безопасны.

После завершения обыска ловушка показывает название и таймер. Новое нажатие E в течение 0,5 секунды обезвреживает её и открывает лут; удерживание E не считается повторным нажатием. Можно отойти или вовремя уклониться. Если время истекло, устройство срабатывает один раз, а припасы остаются в контейнере. Для их получения затем снова нажмите E. Прерванный обыск не раскрывает и не меняет ловушку.

- Электрошок: 18 урона в радиусе 90 игровых единиц, шум 8.
- Мина: 40 урона в радиусе 130, шум 60, эффект взрыва.
- Газ: 4 урона при выпуске и до пяти дополнительных импульсов по 4 урона раз в секунду в радиусе 110. Облако видно пять секунд; выход из него прекращает воздействие. Газ не заражает вирусом.
- Сирена: без урона; создаёт шум на 10 выше порога текущей зоны. Без защиты от ловушек вызывает обычное предупреждение об орде, если общий таймер повторного появления позволяет. Маскировка героя и его рюкзак не приглушают устройство.

Числа урона, радиусы, шум и длительность газа — начальные настройки баланса, отсутствующие в документе. Урон проходит через броню, стойкость и неуязвимость от уклонения/возрождения. Взрыв ловушки пока повреждает только героя. Для облака и взрыва используется существующий сгенерированный атлас эффектов. После активации или обезвреживания состояние сохраняется вместе с комнатой; повторное открытие не срабатывает заново и не добавляет предметы. Как остальные таймеры комнаты, ловушки и газ приостанавливаются в инвентаре, паузе и пока игрок находится в другом помещении. Загрузка чекпоинта создаёт этаж заново по прежним правилам.

**Сапёр** уменьшает урон и шум ловушек на 50/75/100%; третий ранг автоматически обезвреживает их при обыске. Стоимость 150/300/600 ДНК — начальная настройка. Синергия «Неуязвимый» (стойкость 3 + сапёр 3) отображает предусмотренный концептом иммунитет к ловушкам. Он уже достигается третьим рангом сапёра; дополнительный множитель или иммунитет к обычным атакам не добавляется.

Добавлены три перка Выжившего: «Регенерация» (+1/2/3 HP в секунду), «Стойкость» (−10/20/30% входящего урона) и «Второе дыхание» (1/2/3 автоматических возрождения за спуск). Первые два стоят 150/300/600 ДНК, второе дыхание — 200/400/800. Регенерация работает только во время игры, в том числе в бою; пауза, инвентарь, переходы и оконченная попытка не лечат. Она ограничена текущим максимумом HP и не снимает заражение. Стойкость перемножается с оставшимся после брони уроном.

«Танк» (здоровье 3 + стойкость 3) даёт ещё +100 максимальных HP и ещё −50% входящего урона. Получается 260 HP до штрафа заражения; с максимальной стойкостью герой получает 35% урона до брони. «Феникс» (второе дыхание 3 + регенерация 3) возвращает с 50% текущего максимума HP вместо 25%. Для «Феникса» использовано описание из раздела синергий; отдельный взрыв из списка веток не добавляется.

Возрождение происходит на месте и сохраняет врагов, добычу и инвентарь. Обыск, изготовление и перезарядка прерываются без списания незавершённых затрат. Две секунды защиты предотвращают повторную гибель в той же атаке; остаток защиты и возрождений виден в HUD. При фатальном заражении инфекция снижается до 50%, затем здоровье вычисляется с её штрафом. При гибели от урона инфекция сохраняется. Начальные настройки, не уточнённые концептом: обычное возрождение с 25% HP, две секунды защиты, инфекция 50% после вирусной гибели, цены перков.

Потраченное возрождение сразу записывается отдельным полем в существующий чекпоинт, не меняя его этаж, здоровье и содержимое рюкзака. Возврат в комнату, спуск, смерть и загрузка чекпоинта не возвращают потраченные заряды. Новый спуск с крыши восстанавливает лимит; покупка нового ранга увеличивает общий лимит при следующем старте. Старые сохранения без счётчика загружаются с нулём потраченных зарядов. Если браузер запрещает запись, игра сообщает об этом: расход сохраняется только в текущей сессии. Возрождение не увеличивает счётчик смертей и не начисляет бонус ДНК за заражение; этот бонус возникает только при окончательной смерти.

Ветка «Боец» теперь содержит пять обычных перков. Добавлены «Быстрые руки» (+15/30/45% скорострельности), «Тяжёлый калибр» (+1/2/3 цели, пробиваемые сверх первой), «Критический удар» (10/20/30% шанса двойного урона выстрела или ножа) и «Мастер ближнего боя» (+25/50/100% урона ножа). Цены по рангам: быстрые руки — 150/300/600 ДНК, калибр и крит — 200/400/800, ближний бой — 100/200/400. Цены и множитель критического удара ×2 являются начальной настройкой баланса; концепт задаёт шансы, но не силу крита.

Работают четыре боевые синергии из концепта:

- **Берсерк:** «Меткий глаз» 3 + «Критический удар» 3 → +50% урона выстрела, ножа и гранаты при HP строго ниже 30% текущего максимума. Индикатор появляется рядом с боевыми характеристиками; при лечении выше порога исчезает. Для гранаты здоровье проверяется в момент взрыва. Самоповреждение не усиливается.
- **Мясник:** ближний бой 3 + быстрые руки 2 → ещё ×2 урона ножа.
- **Штурмовик:** меткий глаз 2 + тяжёлый калибр 2 → ещё одна пробитая цель.
- **Снайпер:** меткий глаз 3 + крит 2 → ещё ×1,5 урона в голову.

Бонусы урона перемножаются. Пробитие обрабатывает живых противников по расстоянию вдоль линии выстрела, независимо от порядка их появления; один выстрел расходует один патрон. Для каждой цели отдельно считаются попадание в голову/ноги, передняя броня и дистанционное ослабление дробовика. Пробитие не снимает защиту Броневика. Критический результат общий для всех целей одного выстрела/взмаха; гранаты не критуют. Дробовик выпускает шесть отдельных дробин, каждая со своим пробитием и ослаблением по дистанции. Задержка стрельбы делится на множитель скорострельности; перезарядка, задержка и расход выносливости ножа не ускоряются. Переключение оружия не обнуляет задержку. Покупки сохраняются и применяются со следующего старта, как остальные перки. В лаборатории активные синергии видны сразу, условия остальных раскрываются отдельно.

Добавлены «Грузчик» (+5/10/15 кг с любым рюкзаком) и «Мародёр» (+1/2/3 единицы припасов в каждом стационарном контейнере, включая крышу). Оба стоят 150/300/600 ДНК — начальная настройка цены. При третьем ранге обоих включается «Хамстер»: ещё +10 кг и +3 единицы припасов, итого +25 кг и +6 предметов относительно отсутствия этих перков. Использовано описание из раздела синергий концепта; альтернативный «+1 слот рюкзака» из списка веток одновременно не добавляется.

Бонусные предметы берутся из обычного набора припасов соответствующего контейнера, по одной единице за бонус: например, один патрон или один бинт. Они могут объединяться в существующие пачки. Базовая добыча, оружие и прочность брони от покупки перка не меняются. Лут рассчитывается один раз при создании помещения; отмена обыска, повторное открытие и возвращение в комнату не начисляют бонус заново. При нехватке места остаток остаётся в контейнере; оставленные игроком сумки не получают бонусов. Профиль сохраняет покупки, бонусы включаются при следующем старте или загрузке чекпоинта. Как и раньше, загрузка чекпоинта создаёт этаж заново, а не восстанавливает уже обысканные комнаты.

Теперь доступны все шесть рюкзаков. На старте остаётся рюкзак Выжившего, новые встречаются в контейнерах. Надеть запасной можно кнопкой «Надеть» в рюкзаке; найденный — кнопкой «Надеть · обменять старый» прямо в окне обыска. Обмен из контейнера работает даже при полной сетке: старый рюкзак остаётся в этом контейнере. При замене из сетки старый занимает место запасного. Если вещи не помещаются, замена отменяется целиком. При необходимости выполняется автоматическая укладка с сохранением UID, патронов, прочности и ссылок на экипировку. Неудачная укладка не меняет исходное состояние; поиск ограничен, чтобы не блокировать интерфейс.

Выберите оружие в сетке и нажмите нужный слот над ней; в бою переключайтесь клавишами 1–3. Слоты ссылаются на те же экземпляры оружия в сетке, не освобождают их ячейки и не создают копии. Смена оружия отменяет незавершённую перезарядку без расхода патронов и не сбрасывает задержку между выстрелами. При уменьшении числа слотов текущее оружие остаётся в быстром доступе, остальные экземпляры остаются в рюкзаке. Это трактовка дополнительных оружейных слотов для текущей версии инвентаря.

Размер рюкзака учитывают подбор, перенос, поворот, укладка, комбинирование, крафт и сохранения. Старые чекпоинты без типа рюкзака загружаются как Выжившего 6×5; большие сохраняют до 48 предметов. Для шести рюкзаков сгенерирован отдельный атлас. Собственный вес пустых рюкзаков пока равен нулю: концепт задаёт их бонус к переносимому весу, но не массу каждого пустого рюкзака. Надетый рюкзак хранится отдельным слотом, запасной занимает 2×2.

- **Четыре слота защиты.** Голова, торс, руки и ноги; 14 предметов из концепта с индивидуальными весом, защитой и бонусами. Надеть можно из рюкзака, снять — нажатием на занятый слот. Предмет продолжает занимать свои ячейки. Защита складывается и ограничена 90%: буквальная сумма из концепта может превысить 100%, поэтому это явная настройка баланса, предотвращающая бессмертие и отрицательный урон.
- **Прочность и ремонт.** Каждый полученный удар снимает 1–3 п.п. прочности с каждой надетой вещи. Неуязвимость после попадания и уклонение предотвращают износ. При 0% защита и положительные бонусы отключаются; вес, ограничение обзора и штраф скорости остаются. Ремонт выбранной вещи до 100% стоит 1 металл + 1 ткань и занимает 3 секунды до бонуса инженера. Он требует рабочего стола, прерывается движением или уроном и списывает материалы только после завершения. Прочность и слоты сохраняются при смене локации, выбрасывании, подборе и загрузке чекпоинта. Старые бронежилеты без прочности считаются целыми.
- **Вес и перегруз.** Стартовый рюкзак 6×5 соответствует рюкзаку Выжившего: +8 кг к лимиту и −10% всего шума. Начальный лимит — 18 кг. Пока отдельного опыта веток нет, «Выживший.Уровень» трактуется как сумма купленных рангов всех пяти перков ветки Выжившего: каждый даёт ещё 2 кг со следующего старта. Это текущая трактовка неоднозначного поля концепта. Учитываются все предметы, включая надетые вещи и патроны в магазинах. Перегруз: скорость ×0,85, расход сил при беге/ноже/уклонении ×1,25, скорость перезарядки ×0,9. Дистанция уклонения не меняется. Массы брони и ресурсов взяты из концепта; массы патронов и расходников — начальные настройки баланса, доступные в описании предмета.
- **Бонусы снаряжения.** Штрафы/бонусы скорости брони складываются, затем умножаются на перегруз и перки. Тактические перчатки ускоряют перезарядку на 10%, бронеперчатки усиливают нож на 5%. Ограничение обзора шлемов затемняет края игрового поля; интерфейс остаётся видимым. Устойчивость берцев уменьшает тряску камеры при ударе в 1,1 раза. Экзо-ботинки снижают шум на 10%; этот множитель перемножается с рюкзаком и «Призраком».
- **Добыча и изготовление.** В добычу добавлены клей, электроника и все варианты защиты. В офисах чаще лёгкие вещи, ниже — военные и тяжёлые; найденная защита имеет 65–100% прочности. Для вещей использован новый сгенерированный атлас; иконки вырезаются по прозрачным промежуткам. На верстаке доступны ещё шесть рецептов из концепта: кожанка, бронежилет, кевлар, тяжёлая броня, строительная и военная каски. Время изготовления каждого — 5 секунд до бонуса инженера. Всего 15 рецептов изготовления и отдельное действие ремонта.

- Походка героя: цикл сокращён с 96 до 72 единиц пройденного пути, уменьшены размах и подъём стоп. При переносе стопа слегка поворачивается; скорость её движения непрерывна при отрыве и приземлении. Начало и остановка смешиваются со стойкой без переключения позы на пороге. Длины бедра и голени постоянны, исходные текстуры масштабируются равномерно.
- Направление корпуса определяется относительно центра героя с полосой удержания ±9 единиц. Плечо больше не участвует в решении о развороте, поэтому вертикальный прицел не вызывает бесконечное зеркальное переключение. Угол оружия вычисляется отдельно от актуального плеча после обновления камеры и позы; стрельба мышью сохраняется при ходьбе назад.
- Проверка `tests/player_motion_smoke.py` воспроизводит реальные события мыши, вертикальное наведение с обеих сторон, разворот, остановку и сопровождение камерой. Новые архивы для этих исправлений не выпускались.

## Что изменилось в 0.10

- **Восприятие заражённых.** Зомби переходят от покоя к патрулю, замечают героя, проверяют источник шума и осматриваются после потери цели. Перед ними зона видимости больше, чем за спиной. После потери героя они помнят последнюю увиденную или услышанную точку, а не получают его новые координаты. По прибытии осматриваются три секунды и возвращаются к патрулю. Время на подход ограничено расстоянием и скоростью, максимум 50 секунд. Состояние врагов сохраняется при переходах между комнатами текущего этажа.
- **Фонарь и скрытность.** В коридорах паркинга дальность обнаружения обычным врагом впереди — 125 единиц без фонаря, 330 с работающим фонарём; в освещённых локациях — 430. Вплотную герой обнаруживается с любой стороны. Объект 0 видит на 550 единиц независимо от фонаря. Это текущие настройки баланса. На HUD показано, заметили ли героя или ищут его; «!» над врагом означает обнаружение, «?» — проверку или поиск. Густота затемнения теперь учитывает разряженную батарею.
- **Звуковые ориентиры.** Выстрел, взрыв, шаги и шумный обыск передают врагам координаты источника. Крикун привлекает заражённых к себе. Громкость определяет дистанцию слышимости. Тихая ходьба позволяет подойти ближе, чем бег. Шум для вызова орды по-прежнему считается за пять секунд. Враг из соседней закрытой комнаты не получает сведения о герое: комнаты моделируются отдельно.
- **Прицельные атаки.** Плевун начинает прицеливание, когда видит героя, и фиксирует точку выстрела при подготовке атаки. Если герой после этого ушёл, кислота летит в прежнюю точку. Новую прицельную атаку по невидимой цели зомби не начинает. Уже начатые удары и рывки заканчиваются обычным образом.
- **Ещё два перка.** «Лёгкие ноги» повышает скорость ходьбы и бега на 10/20/30% (150/300/600 ДНК). «Связь с вирусом» снижает скорость передвижения заражённых, включая рывки, на 10/20/30% (200/400/800 ДНК). Изученные перки применяются со следующего старта. Дальность уклонения героя остаётся прежней.
- **Синергия «Призрак».** Открывается автоматически при «Лёгких ногах» 3 и «Тихом обыске» 3; уменьшает весь шум на 50%, включая громкость для слуха врагов. Бонус умножается на снижение шума обыска. Лаборатория показывает условия синергии и позволяет отфильтровать восемь доступных перков по пяти веткам.
- **Скачивание через сервер.** На серверной странице есть ссылка «Скачать · ZIP» с передачей архива по частям через HTTP Range. В автономном HTML она не нужна и не добавляется. Доступность этого способа с вашего компьютера зависит от доступа к предпросмотру облачной среды. Резервная выдача четырьмя файлами и сборщиком Windows сохранена.

В этой версии реализована базовая модель восприятия, но не обучение ИИ на привычках игрока, стайное окружение и мутации. Персонажи используют существующие изображения; новых анимационных атласов в 0.10 нет.

## Изменения 0.9

- **Шум и орды.** Пистолет создаёт 20 шума, дробовик — 40, взрыв гранаты — 60; ходьба — 2/с, бег — 10/с до множителей снаряжения и перков. В рабочей сборке стартовый рюкзак уменьшает эти значения на 10%. Учитываются последние пять секунд игрового времени. Громкий обыск тоже создаёт шум, распределённый по времени работы; уже открытый контейнер не шумит повторно. Превышение порога предупреждает об орде за три секунды. Повторное срабатывание возможно не раньше чем через 25 секунд. В офисах и на крыше приходят два врага, в других зонах — четыре; одновременно живых врагов не больше 40. Они входят через существующие двери или лифт. Если герой стоит у единственного входа, появление откладывается до безопасного расстояния. Переход в комнату не сбрасывает предупреждение, спуск на другой этаж сбрасывает шум.
- **Заражение «Некрос-7».** Попавшая ближняя атака заражает на 10 п.п.; после этого заражение растёт на 0,12 п.п./с. Эти два значения — начальная настройка баланса: документ задаёт стадии, но не скорость роста. Уклонение и защита от повторного урона блокируют также заражение. Кислота, взрыв и окружение не считаются укусами. При 30% максимальное здоровье падает на 10%, при 60% — на 30%. С 60% появляется слабая дымка по краям, с 90% — критическое предупреждение. При 100% герой погибает и получает дополнительно 50% заработанной за попытку ДНК, однократно.
- **Лечение инфекции.** Аптечка снимает 20 п.п. заражения и лечит, даже если здоровье было полным. Антидот снимает всё заражение и возвращает обычный предел HP, но сам не восстанавливает потерянное здоровье. При отсутствии заражения антидот не расходуется. Заражение хранится в чекпоинте, сохраняется между комнатами и этажами; новый спуск с крыши начинается без него. Старые чекпоинты загружаются с нулевым заражением.
- **Изготовление на этаже.** Встаньте рядом с обыскиваемым столом или техническим ящиком, откройте I → «Изготовление». Выберите рецепт: рюкзак закроется и работа начнётся на этаже. Бой продолжается; движение, прыжок, уклонение, E или полученный урон отменяют работу. Ресурсы и ДНК списываются только по завершении. Проверка свободного места учитывает освобождение ячеек ингредиентами. В паузе и рюкзаке таймеры опасностей не идут.
- **Новые предметы и перки.** Ткань, химикаты и антидот добавлены в добычу; для них сгенерирован отдельный атлас. В лаборатории теперь шесть перков. «Иммунитет» уменьшает заражение и скорость роста на 20/40/60%, «Тихий обыск» — шум обыска на 30/60/90%, «Инженер» — время изготовления на 20/40/60%. Иммунитет и инженер стоят 150/300/600 ДНК; тихий обыск — 100/200/400. Старые покупки сохраняются.

| Рецепт                 | Ресурсы              | Базовое время |
| ---------------------- | -------------------- | ------------- |
| Бинт                   | 2 ткани              | 2 с           |
| Аптечка                | 3 ткани + 1 химикат  | 3 с           |
| Антидот                | 2 химиката + 50 ДНК  | 3 с           |
| 15 патронов 9 мм       | 1 порох + 1 металл   | 2 с           |
| 10 патронов 12 калибра | 2 пороха + 2 металла | 3 с           |
| Граната                | 2 пороха + 1 металл  | 4 с           |

Пороги шума — настройка текущего баланса: крыша 100, офисы 90, лаборатории 80, апартаменты 70, торговый центр 100, паркинг 65, бункер 90. В 0.9 потеря цели ещё отсутствовала; она добавлена в 0.10. Галлюцинации с ложными врагами и контейнерные ловушки пока не реализованы. Дымка не размывает персонажа и прицел.

## Изменения 0.8

- **Постоянная ДНК.** За Ходока начисляется 5, Бегуна — 8, Толстяка — 20, Крикуна — 10, Плевуна — 12, Броневика — 25, Объект 0 — 250. Награда выдаётся один раз при смерти врага. ДНК, покупки, убийства, смерти, эвакуации и лучший спуск сохраняются отдельно от чекпоинта и переживают смерть героя.
- **Первые три перка.** Лаборатория доступна до старта и после завершения попытки. «Крепкое здоровье» даёт +20/40/60 HP и стоит 150/300/600 ДНК по уровням. «Меткий глаз» даёт +10/20/30% урона огнестрельного оружия, «Быстрый обыск» сокращает время на 20/40/60%; каждый стоит 100/200/400 ДНК. Купленные улучшения применяются при следующем старте, включая продолжение с чекпоинта. При продолжении здоровье берётся из чекпоинта; повышенный максимум не даёт бесплатного лечения.
- **Выносливость.** Запас 100, бег на Shift ускоряет движение в 1,5 раза и тратит 10/с, нож — 15 за удар, уклонение — 25. Восстановление — 15/с вне боя, 5/с рядом с активным противником. После полного истощения бег снова доступен при 20 единицах. Во время удара ножом и рывка восстановление приостанавливается.
- **Уклонение на Q.** Рывок на два тайла (96 единиц) в сторону движения или взгляда. Длится 0,3 секунды с неуязвимостью; повтор доступен через 1,5 секунды. Стены ограничивают дистанцию. На HUD видны выносливость и готовность рывка.
- **Обыск.** Базовое время составляет 1–5 секунд: стол — 1,5, ящик и медицинский контейнер — 2, сундук — 3, сейф — 5. Движение, урон и уклонение прерывают обыск. Перк сокращает длительность.

Профиль использует localStorage `elevator-to-hell-progress-v1`. Он сохраняется в текущем браузере; очистка данных сайта удалит его. В автономном файле хранение зависит от разрешений браузера и расположения файла. Если запись покупки заблокирована, лаборатория сообщает, что улучшение действует только в этой сессии. Старые чекпоинты 0.6–0.7 загружаются с полной выносливостью.

## Изменения 0.7

- **Единый масштаб.** Обычная дверь — 148 игровых единиц, герой — около 124. Коридоры, комнаты и крыша используют эту опору; мебель масштабируется вместе с архитектурой без растягивания. Размеры специальных крупных противников сохранены. Передние ящики и трубы уменьшены, подвесные детали привязаны к потолку.
- **50 разных интерьеров.** Для этажей 50–2 и B1 сгенерированы пять новых атласов по десять участков. Каждый этаж получает свой участок: приёмную, переговорную, архив, серверную, карантин, прачечную, кинотеатр, мойку и другие. Секции соединяются с коридорами с общей линией пола, разным порядком и зеркальными крыльями. В каждом новом участке есть обыскиваемая мебель. Крыша остаётся отдельной стартовой локацией.
- **Опора ног.** Ходьба героя рассчитывается по пройденному расстоянию. Бедро и голень имеют фиксированную длину, колено сгибается вперёд, ближняя и дальняя ноги чередуются. В фазе опоры стопа сохраняет мировую координату, в переносе поднимается максимум на восемь единиц. Созданы отдельные текстуры корпуса и ног; корпус имеет естественный контур под поясом. Скорость движения уменьшена с 163 до 145 единиц/с, звуки шагов связаны с контактом стоп. Существующие цельные позы прыжка и смерти сохранены.

Файлы `gait.js` и `sector-layouts.js` содержат расчёт походки и измеренные координаты новых интерьеров. `dist/locations-v0.7.webm` показывает восемь этажей с героем и зомби.

## Возможности предыдущих версий

- **Игровая крыша.** Разбитый вертолёт, припасы, охрана и дверь лестницы справа. Через неё можно сразу перейти на этаж 50. Дробовик и патроны находятся в ящике охраны, медикаменты — в красном кейсе.
- **Свободный спуск.** Механика предохранителя удалена. Лифты доступны без обязательного обыска технической комнаты. В B1 эвакуация по-прежнему требует уничтожить босса.
- **Разные этажи.** Каждому этажу назначены своя последовательность архитектурных секций, название, расположение комнат и мебели, освещение, передний план, добыча и группы противников. Нижние этажи каждой зоны получают дополнительные крылья. Всего 51 планировка с учётом крыши и 173 входа в комнаты. Некоторые комнаты имеют вход справа. Фоны собираются один раз в цельное изображение, а зоны взаимодействия получают ровно то же преобразование, что двери и мебель.
- **Глубина сцен.** Добавлены независимый дальний вид за окнами, углубления проёмов, перспективные швы пола, контактные тени и сгенерированные передние планы с небольшим параллаксом. Это вид сбоку с несколькими слоями глубины, не полноценная 3D-сцена.
- **Рука героя.** Отдельные изображения для пистолета, дробовика, ножа и перезарядки. Плечо привязано к корпусу; прицел, трассер и вспышка используют общий источник выстрела.
- **Кислотный плевок.** Добавлены текстурированные кадры сгустка, капель, попадания и пузырящейся лужи. Снаряд поворачивается по траектории. Попадание наносит 12 урона, активная лужа остаётся на пять секунд.
- **Сетчатый инвентарь 6×5.** Предметы занимают разное число ячеек, поворачиваются, складываются в ограниченные пачки и перемещаются. Пистолет занимает 2×1, дробовик — 3×1, броня — 2×2. Окно обыска позволяет забрать отдельный предмет или всё, что поместится. Остальное остаётся в контейнере без повторной генерации.

Планировки используют 50 разных тематических участков, общие соединительные коридоры шести зон и четыре основы боковых комнат. Полностью отдельные панорамы для всех помещений не создавались. Передние планы не создают невидимых препятствий: герой проходит за ними. Контейнеры и двери размечены по видимой графике.

## Предметы и бой

В контейнерах встречаются 42 типа добычи, включая 14 видов защиты, шесть рюкзаков, клей и электронику. Состав зависит от типа контейнера и диапазона этажей. Пистолет и нож выдаются на старте. Смешанная трава получается комбинированием.

- Пистолет: 12 патронов, базовый урон 10. Дробовик: 6 патронов, 6 дробин по 10 урона со снижением на расстоянии и разбросом.
- Попадание в голову даёт ×2 урона, в ноги — ×0,5 и замедление. Броневик блокирует 70% урона спереди.
- Аптечка восстанавливает 55 HP, бинт — 20, зелёная трава — 25, смесь трав полностью восстанавливает здоровье. Вода и консервы дают небольшое лечение. При полном здоровье лечебный предмет не тратится.
- Зелёная + красная трава → смесь. Порох + металлолом → 15 патронов 9 мм на рабочем месте. Если результат не помещается, ингредиенты сохраняются.
- Защита надетых вещей четырёх слотов складывается до предела 90%; сломанные вещи не защищают. Фонарь расходует заряд, батарейки восстанавливают его.
- Патроны, гранаты и лечение списываются из инвентаря. Боезапас в магазине хранится в самом оружии, включая выброшенный или сохранённый экземпляр.

Зомби имеют подготовку атаки, удар и восстановление; из зоны удара можно выйти. Бегун делает рывок, Крикун призывает пять заражённых, Толстяк после смертельного попадания пульсирует 0,65 секунды и взрывается: восемь кадров разрыва, кровь, слизь, падающие фрагменты и пятна на полу. Взрыв однократно наносит 20 урона рядом стоящему герою и 45 другим зомби. Тело Толстяка исчезает при взрыве; остальные зомби заканчивают падение лежащим телом. Следы крови, слизь, тела и добыча сохраняются при возвращении в комнату в пределах этажа.

## Остальной концепт

Полный документ пользователя находится в `docs/concept-current.txt`, художественный — в `docs/art-reference.txt`. Мета-база, остальные рецепты и типы оружия, остальные перки и их синергии, NPC, дополнительные сюжетные боссы, кооператив и полноценный саундтрек пока не реализованы. Отображение надетых вещей и сменного рюкзака на теле героя пока не реализовано: снаряжение видно в инвентаре и влияет на характеристики. Сенсорное управление отдельно не дорабатывалось. У всех шести обычных типов зомби по восемь новых кадров движения; у Объекта 0 также подключены восемь кадров ходьбы и отдельные восемь кадров ближнего удара и залпа кислотой. Походка с расчётом опоры стоп используется у героя. У всех шести обычных типов зомби новые восьмикадровые циклы падения; у Объекта 0 тоже восемь кадров падения; у героя также восемь кадров падения с закреплённой опорой.

Проверка Крикуна: `GAME_URL=http://127.0.0.1:3000 python3 tests/screamer_smoke.py` — восемь поз, опора стоп, привязка волны ко рту, призыв при 30/60/144 кадрах/с, прерывание попаданием и смертью, лимит врагов.

Положение тела проверяется командой `GAME_URL=http://127.0.0.1:3000 python3 tests/corpse_position_smoke.py`: три точки локации, оба направления, три положения камеры и возвращение в комнату. Скрипт также записывает `dist/boss-death-position.webm`: один босс погибает справа от героя, затем герой движется, а тело остаётся в прежнем месте локации. В обычных демонстрациях `record_enemy_preview.py` гибель пары врагов запускается сценарием после показа атаки — это не правило поведения в игре.

**Окружение и интерфейс.** Этажи состоят из цельных тематических панорам с уникальными ориентирами, 58 подходящими по размеру предметами на двух планах, следами заражения и анимированным освещением. Отдельные настенные накладки отключены: они закрывали мебель и окна и выглядели как предметы внутри стены. За всеми окнами этажа теперь одна непрерывная сгенерированная панорама города; в офисной комнате прежняя сетка из шести стёкол заменена одним большим окном, а в апартаментах — одним стеклом под шторами. В комнатах вид за окном нарисован прямо в общей текстуре помещения, без прямоугольной накладки; в коридорах общая панорама смешивается с существующим стеклом. Поверх видны дождь, далёкие пожары и отблески. Повреждённые лампы мерцают у нарисованных светильников. У героя исправлена текстура плеча. Быстрые слоты размещены по центру, показывают иконки и текущий запас; их можно настроить в рюкзаке выбором или перетаскиванием предмета, настройки сохраняются локально. Выброшенные припасы отмечены сумкой и подписью. Проверки: `tests/dressing.test.mjs`, `tests/atmosphere.test.mjs`, `tests/quickslots.test.mjs`, `tests/quickslots_smoke.py`, `tests/floor_depth_smoke.py`.
