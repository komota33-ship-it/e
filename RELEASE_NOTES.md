Тестовая сборка «Лифт в ад» для Windows 64-bit на Godot 4.6.3.

Распакуйте ZIP в отдельную папку и запустите `Lift-v-ad.exe`. Файл `Lift-v-ad.pck` должен лежать рядом с исполняемым файлом. Интернет для запуска не требуется.

Все 50 этажей башни получили отдельные длинные непрерывные фоны, без разрывов между секциями. Двери и предметы подогнаны под рост героя и заражённых. Обновлён экран убежища: комнаты, припасы, улучшения и спуск видны одновременно, а обитатели появляются только после спасения.

Это рабочая сборка для проверки. Исходный проект Godot и браузерный прототип доступны в репозитории.
